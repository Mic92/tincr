# Fuzzing

Coverage-guided fuzzing with [`cargo-fuzz`](https://github.com/rust-fuzz/cargo-fuzz)
for the parsers that see peer- or TUN-controlled bytes. Every target has
one property: it never panics. A panic on the event-loop thread exits
the daemon, so any crash here is a remote (or local) DoS.

## Targets

| Target        | Harness                          | Covers |
| ------------- | -------------------------------- | ------ |
| `mss_clamp`   | `tincd::fuzz::mss_clamp`         | `mss::clamp` (VLAN, IP-in-IP, v4/v6 TCP options) |
| `route_frame` | `tincd::fuzz::route_frame`       | `route`, `route_mac`, ICMP error builders, ARP/NDP replies, `fragment_v4` |
| `socks_reply` | `tincd::fuzz::socks_reply`       | SOCKS4/5 reply parsing |
| `tso`         | `tinc_device::fuzz::tso`         | `tso_split` on `[vnet_hdr][IP]` |
| `gro`         | `tinc_device::fuzz::gro`         | `GroBucket::offer`; flushed output goes back through `tso_split` |

The harnesses live in the library crates behind the `fuzzing` feature
(and `cfg(test)`, which runs a smoke test over them), so they can reach
`pub(crate)` code. The targets here are one-line wrappers.

`seeds/<target>/` holds small well-formed inputs that get past the
length and ethertype checks. They are generated by `./gen-seeds.py`;
rerun it when a harness input format changes.

## Running

The `fuzz` dev shell sets `RUSTC_BOOTSTRAP=1`, so the nixpkgs rustc
accepts cargo-fuzz's unstable flags:

```sh
nix develop .#fuzz
cargo fuzz run -s none mss_clamp fuzz/corpus/mss_clamp fuzz/seeds/mss_clamp -- -max_total_time=300
```

`-s none` is required: nixpkgs rustc does not ship the sanitizer
runtimes. The code under test is safe Rust, so ASan would add little.

## Triage

```sh
cargo fuzz run  -s none <target> fuzz/artifacts/<target>/crash-<hash>
cargo fuzz tmin -s none <target> fuzz/artifacts/<target>/crash-<hash>
```

Fix the class, not the input (see PLAN.md, C2). If the fix is not
covered by a type or lint, add the minimised input as a `#[test]` next
to the harness in `src/fuzz.rs`.

Known crashes, fixed in PLAN.md Phase 1:

- `mss_clamp`: `mss.rs` reads past the frame on a truncated MSS option
  (bug_001).
- `tso`: `tso_split` slices the IPv6 address span before checking that
  `csum_start` covers an IPv6 header.
